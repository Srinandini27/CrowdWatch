# CrowdWatch - Neighborhood Alert & Reporting System

## Description
A full-stack civic tech platform for residents to report local issues and receive SMS alerts. Features admin view for issue management.

## Tech Stack
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB
- Notifications: Twilio API
- Map Integration: Mapbox (future extension)

## Features
- Submit reports for local issues
- Admin dashboard to view and manage alerts
- SMS alerts to subscribed users

## Setup
1. Clone repo
2. Setup `.env` with MongoDB and Twilio credentials
3. Run `npm install` in both client and server
4. Start backend with `node server/index.js`
5. Start frontend with `npm start` in `client/`
